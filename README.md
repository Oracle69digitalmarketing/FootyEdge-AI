# FootyEdge AI

Production-grade football predictive analytics engine.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   npm install
   ```

2. Configure environment variables in `.env`.

3. Run the backend:
   ```bash
   uvicorn api:app --host 0.0.0.0 --port 8000
   ```

4. Run the frontend:
   ```bash
   npm run dev
   ```
